The Problem

Between real estate clients, dance students, and personal life, my contact list grew into hundreds of inconsistent entries: "john smith" next to "John  Smith," phone numbers in five formats, duplicates everywhere, and no record of how I knew people. Cloud CRMs solve this by taking your data; I wanted a tool that solves it while keeping the data mine.

What I Built

  • Multi-source import: pulls contacts in from CSV, Excel, vCard, JSON, and Google/Apple/Outlook exports — hundreds at a time.
  • Intelligent cleaning: normalizes names (handles prefixes and suffixes like Dr. and Jr.), standardizes phone numbers to international E.164 format, validates email syntax, and finds duplicate people with fuzzy matching before merging them.
  • Enrichment engine: a tiered lookup system (AI-powered search first, then targeted APIs) proposes updates like current job or company — but nothing changes without my explicit approval. Human-in-the-loop by design.
  • Terminal UI: built with Textual, a modern Python TUI framework — fast, keyboard-driven, and it runs anywhere Python runs, including straight off a USB drive.

Design Principles

  • Local-first: the database is a file on my machine, synced by tools I control — no cloud account, no vendor lock-in.
  • Portable: designed to travel on a thumb drive and work across every machine I plug it into.
  • Trust but verify: automated suggestions, human decisions. The system never silently rewrites a contact.
