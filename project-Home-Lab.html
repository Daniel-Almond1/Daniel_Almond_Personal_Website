Tuesday

Self-Hosted AI Assistant & Home Lab

I turned a mini-PC into an always-on home server (affectionately named "Sir-Serves-A-Lot") running a sandboxed AI assistant, scheduled finance automations, and a media server my whole family uses.

What It Is

Tuesday is a personal AI assistant that lives on my own hardware — a Beelink mini-PC running Linux — instead of someone else's cloud. I message her on Telegram and she handles my calendar, tasks, and contacts, tracks my crypto portfolio and net worth, and sends me automated reports. She runs inside a security sandbox that controls exactly what the AI agent is allowed to touch.

What's Running On It

  • Tuesday (AI agent): an always-on assistant built on an open agent platform, wrapped in a security sandbox with an explicit network policy. She talks to the Claude API for reasoning and to approved services (calendar, search, market data) for real-world tasks.
  • Scheduled finance automations: Python scripts fetch crypto and market prices, recalculate my net worth, and generate a monthly finance summary — automatically, on a schedule.
  • Per-message cost tracking: a script logs the API cost of every AI interaction, so I always know what the assistant actually costs to run.
  • Audiobook automation: a wishlist-driven pipeline that fetches and organizes audiobooks automatically.

How It's Managed (The Part Employers Care About)

  • Infrastructure as files: the assistant's configuration, behavior rules, and scheduled tasks are version-controlled files — the server is deployed from them, not hand-edited.
  • One-command deploys: a PowerShell script pushes configuration and scripts to the server over SSH (key-only authentication), and a companion script smoke-tests the assistant after every deploy.
  • Security-first: the AI runs inside a sandbox with a declared network policy; remote access is restricted to key-based SSH. Building this taught me more about Linux administration, networking, and AI-agent security than any course could.
